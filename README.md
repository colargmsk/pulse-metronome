# Pulse 节拍器

一个单文件的在线节拍器，使用 Web Audio API 做精确的前瞻式节拍调度，适合日常练习、录音参考和节奏训练。

## 功能

- **精准计时**：基于 Web Audio 音频时钟调度，不依赖界面动画或普通 `setInterval` 累加节拍。
- **BPM 20–300**：滑块、±1 微调和 Tap Tempo 多种调速方式。
- **1–16 拍/小节**：可点击任意拍点自定义重音，并一键强调第一拍。
- **11 种细分**：四分、八分、三连音、十六分，直至十一连音。
- **Swing 摇摆律动**：双数细分可切换为长—短律动。
- **四种音色**：经典、木质、电子、滴答，支持音量调节。
- **计时器**：1/3/5/10/15 分钟自动停止，带环形倒计时动画和最后 10 秒提示。
- **演奏大屏**：隐藏设置界面，只保留大号 BPM、摆锤、拍点与走带控制。
- **细节体验**：摆锤缓停动画、深浅主题、全屏、响应式布局、设置本地保存、屏幕常亮。

## 使用

直接用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务器。首次点击开始后浏览器会解锁音频。

快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 开始 / 停止 |
| `T` | Tap Tempo |
| `↑` / `↓` | BPM ±1 |
| `Shift` + `↑` / `↓` | BPM ±5 |
| `F` | 进入 / 退出演奏大屏 |
| `Esc` | 退出演奏大屏 |
| `M` | 静音 / 恢复 |

## 技术说明

节拍器使用 Web Audio API 提前调度音频事件，并通过 Web Worker 维持调度循环。每次定时以音频时钟为基准递增，避免界面刷新、标签页切换或浏览器定时器抖动造成节拍漂移。
